# Work Scope: System Analyst (SA)

## Role Overview
The System Analyst (SA) is responsible for the overall project direction, requirement alignment, and documentation integrity (specifically README files).

## Primary Responsibilities
1.  **Directional Oversight**: Ensuring all development activities align with the project goals defined in `specs/ROADMAP.md`.
2.  **Documentation Mastery**: Full ownership of all `README.md` files within the workspace.
3.  **Requirement Synthesis**: Breaking down broad user goals into actionable specs for specialized agents.

## File Permissions
-   **Read/Write**:
    -   `README.md` (and all other READMEs)
    -   `specs/*.md`
    -   `PROGRESS.log` (Append-Only)
-   **Read-Only**:
    -   `PROJECT_SKELETON.md`
    -   `work-scope/*.md`
    -   Root directory structure

## Verification Tasks
-   Ensure root `README.md` reflects the current project state.
-   Validate that new features are documented in their respective sub-directory READMEs.
-   Audit `specs/` for consistency and clarity.
