# Requirement Gathering Best Practices

To ensure high-quality software delivery, consider the following dimensions during the interview phase:

## 1. Functional Requirements
- What is the "Happy Path"?
- What are the critical edge cases?
- Are there specific validation rules for inputs?

## 2. Technical Constraints
- Compatibility with existing libraries (e.g., Vue 3, Spring Boot 3.4).
- Database schema impacts.
- Performance requirements (e.g., response time for search).

## 3. UI/UX Standards
- Responsiveness (Mobile vs. Desktop).
- Accessibility (WCAG).
- Consistency with established component patterns (e.g., Sidebar, Modal).

## 4. Security
- Authentication & Authorization.
- Data sanitization (XSS/SQLi prevention).
- Sensitivity of the data being handled.
